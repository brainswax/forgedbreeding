# Estimated Buck Profile Template  
**For young / unappraised bucks**  
**Last updated:** 2026-07-27  

Use this template to create a reusable profile for any buck that does not yet have his own Linear Appraisal scores.  
Feed the completed profile to the AI together with `GOALS.md` and `LA_REPORT_GUIDELINES.md` so he can be included in individual, pairing, and herd reports on a comparable basis with appraised bucks.

---

## How to Use

1. Fill in the header and parental data.
2. Add any available daughter (or other progeny) LA summaries for the sire.
3. Write a short synthesized **Estimated Transmitting Profile**.
4. Note confidence level and major gaps in the data.
5. Save the completed profile (e.g. `ESTIMATED_BUCK_[Name].md`) and include it whenever generating reports that involve this buck.

## Guidance for Filling the Profile

- Prefer actual linear numbers over category letters when both exist.
- When the sire has multiple appraised daughters, look for **patterns** (e.g. “4 of 5 daughters have MSL ≤ 18”) rather than single anecdotes.
- Be conservative on low-heritability traits — parental scores give weaker predictions.
- Explicitly call out any trait where both parents are weak (higher risk of the buck also being weak there).
- Explicitly call out any trait where both parents (or the sire’s daughters) are strong — these are the best candidates for “likely strengths.”
- Update the profile when new daughter appraisals or the buck’s own future LA become available.
